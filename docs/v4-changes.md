# 추천 로직 v4 변경 사항

2026-10-07 적용. 기존 분석 보고서는 v3 당시의 감사 기록이다.

## 수정한 핵심 원인

실제 Yahoo 응답을 확인한 결과 `range=max&interval=1d`가 AAPL·S&P500에는 3개월봉, 삼성전자에는 월봉을 반환했다. 기존 파서는 이를 일봉으로 받아 지표와 승률을 계산했다. v4는 2011-01-01 이후 명시적 period1/period2와 interval=1d를 요청하며 응답 dataGranularity가 1d가 아니면 거부한다. 이전 파일의 승률과 v4 승률은 같은 데이터 단위가 아니므로 단순 비교하면 안 된다.

## 수집 및 운영

- Stooq 우선 요청 제거, Yahoo 명시 일봉 수집. 수정종가 비율로 OHLC 일관 조정, 시가·거래량·원종가 보존.
- 알려진 KOSDAQ 심볼 우선 매핑, 한국 거래소 대체 경로.
- 본문 수신까지 6초 제한, 최대 2회 시도, 동시 수집 8개.
- 최초 과거 이력 저장 후 이후 370일 갱신. 겹치는 조정가격 비율로 이전 이력 갱신. 종목/통화/거래소가 다른 캐시 병합 금지.
- 날짜 중복/순서/가격 일관성 검사, 미완료 정규장 봉 제외.
- 마지막 날짜와 실패 사유 저장. 캐시만으로 복구한 종목과 5일보다 오래된 자료는 추천 제외.
- 국가별/전체 성공률 70% 및 지수 3개 정상 수집이 충족되지 않으면 기존 공개 파일 유지하고 실패.
- Actions 총 12분, 데이터 단계 9분 제한. 새 코드 push는 이전 빌드 취소. 문서만 바꾸면 수집을 재실행하지 않음.
- Actions history cache로 이후 빌드에 과거 자료 재사용. 실제 데이터 변경 뒤 Pages 배포는 기존 설정 사용.

## 추천과 통계

- 역사와 현재 동일한 상승 200일선·가격·매수구간·첫 진입 조건 사용. 박스폭 20% 미만 조건 현재에도 적용.
- 다음 거래일 시가 진입, h번째 보유 봉 종가 청산. 동일 기간 내 겹치는 사건 제외.
- 시간순 앞 70%에서 보유기간 선택. 학습 거래 청산이 경계 이후면 제외. 뒤 30%는 표시 통계.
- 학습 20거래 이상·양의 순평균수익, 검증 10거래 이상·양의 순평균수익만 신호로 표시.
- 종목 내 신호 선택도 학습 순평균수익 사용. EV는 비용 차감 평균수익률, 손실 미관측 손익비는 null.
- 비용은 한국 0.3%, 미국·일본 0.2% 왕복 가정이다. 실제 브로커 요금이나 모든 세금의 정확한 재현이 아니다.
- RS는 현재 성공한 국가별 종목의 순위. 역사 RS 필터·시장필터·포트폴리오 자본 제약을 검증한 실전 승률은 아니다.
- 여러 신호를 검증 결과로 선별하는 편향이 남으므로 앞으로의 독립 신호 추적이 필요하다. 70/30 분리는 전체 전략 수익을 보증하지 않는다.
- 계절성은 고정 10거래일·10개 완료 연도, 오늘부터 2일 이내 예정 날짜. 과거 최적 날짜/기간 선택 제거. 탐색 통계로 표시.
- ATH/rolling extrema를 선형 시간으로 계산. 현재 구간 신호만 출력하고 차트 수치 표시 정밀도를 줄여 JSON 경량화.
